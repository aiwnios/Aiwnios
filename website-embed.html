What is HolyC?

HolyC is a programming language created by Terry Davis for TempleOS. It combines C-like syntax with unique features like inline assembly and real-time compilation.

Getting Started

Click in the canvas above to focus. Type HolyC code directly and press Enter. Try: "Hello World!\n"; or "1+2+3;"

Features

Full HolyC compiler, graphics support, file system access, and more - all running locally in your browser via WebAssembly.

Keyboard Shortcuts

Escape: Release keyboard focus. The environment supports TempleOS-style DolDoc commands and editors.
